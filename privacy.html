プライバシーポリシー

最終更新日: 2026年9月24日

1. 利用者

本アプリ「kakeibo-n8n」は、運営者本人の家計記録のためだけに使用します。運営者以外のユーザーは利用しません。

2. 取得する情報

運営者本人の Google アカウントに対して、次の情報にアクセスします。

  • Gmail: 特定のラベルが付いたクレジットカード利用通知メールの本文と受信日時
  • Google スプレッドシート: 記録先として運営者本人が指定したスプレッドシート

3. 利用目的

取得した情報は、メールから利用日・金額・利用先を取り出し、運営者本人の Google スプレッドシートに記録するためだけに使用します。

4. 保存と管理

処理は運営者本人が管理するサーバー上で行います。Google から発行された認証情報は暗号化して保存し、サーバーの管理画面はインターネットに公開していません。

5. 第三者への提供

取得した情報を第三者に提供・販売・共有することはありません。広告や機械学習モデルの学習にも使用しません。

6. Google API サービスのユーザーデータに関するポリシー

本アプリが Google API から受け取った情報の使用および他のアプリへの転送は、Google API Services User Data Policy(Limited Use の要件を含む)に従います。

7. アクセスの取り消し

本アプリへのアクセス権は、Google アカウントのサードパーティ製アプリの管理画面からいつでも取り消せます。

8. お問い合わせ

GitHub Issues からご連絡ください。
